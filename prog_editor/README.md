# 《三国志英杰传》程序与数据修改器 (Prog Editor)

基于 Python 和 Tkinter 开发的独立《三国志英杰传》（DOS / Big5 版）主程序（`Main.exe`）、武将基础数据（`Bakdata.r3`）、全章节剧情剧本台词（`Snr*m.r3`）以及战斗与事件剧本指令（`Snr*d.r3`）综合修改器。
本工具专门用于修改游戏程序本体行为、384 名武将的三维能力、剧情对白文本以及战场条件/单挑/AI/事件指令，**非存档编辑器**。

## 目录结构

```
prog_editor/
├── patches.py        # 11 种经典程序功能补丁定义表 (Main.exe 偏移)
├── bakdata.py        # 384 位武将武力、智力、统御三维基础数据解析与回写引擎 (Bakdata.r3)
├── snr_manager.py    # 0~4 章剧情文本与武将对白解析、重构回写与备份引擎 (Snr0m.r3 ~ Snr4m.r3)
├── snrd_manager.py   # 0~4 章战斗部署、触发器条件、单挑、AI改变及事件开关指令引擎 (Snr0d.r3 ~ Snr4d.r3)
├── deploy_dialog.py  # 30 人我军/敌军部队展开部署编辑器窗口 (坐标/主将/回合数/兵种/等级/出场/AI)
├── patcher.py        # 游戏目录校验、Main.exe/Bakdata.r3/Snr*m.r3/Snr*d.r3 读写、自动备份与一键还原控制器
├── ui.py             # 基于 Tkinter/ttk 的多标签页图形界面 (系统补丁 + 武将能力 + 剧情台词 + 剧本指令)
├── main.py           # 启动入口文件
└── README.md         # 使用说明文档
```

## 运行方式

在项目根目录下执行：

```bash
python3 prog_editor/main.py
```

或者直接指定游戏目录启动：

```bash
python3 prog_editor/main.py ./backend/reko3
```

## 核心三大功能模块

### 1. 💬 剧情对白与台词修改 (SNRM)
在**“剧情对白与台词修改”**标签页中：
* **全章节自由切换**：
  * 支持 0~4 全部 5 个章节：序章（群雄討董）、第一章（界橋之戰）、第二章（官渡之戰）、第三章（赤壁之戰/蜀漢建國）、第四章（蜀魏最後決戰）。
  * 自动解析 8000+ 条真实剧情对白与旁白。
* **搜索与类型过滤**：
  * 支持按“全部 / 仅武将对白 / 仅旁白”快速过滤。
  * 搜索栏支持按说话人姓名或台词内容实时模糊搜索。
* **台词多行编辑与说话人自由置换**：
  * 选中对白后，右侧大文本框（Text）直接显示完整台词，支持打字修改与换行排版。
  * **说话人可任意更改**：下拉框支持在“旁白”与全 384 位武将之间自由切换（例如把刘备的台词改成曹操或诸葛亮说）。
  * **Big5 编码实时合规检测**：输入包含非繁体字或生僻字时，界面会实时黄色告警提示无法编码的字符，防止游戏中出现乱码。
* **自动重构与保存**：
  * 字数变长或变短时，底层引擎会自动重新计算各页的 2 字节小端偏移表并打包回写，直接在游戏中完美呈现！
  * 提供“💾 保存当前章节”及全局统一保存，首次修改自动创建 `SnrXm.r3.bak`。

### 2. 🎖 武将三项能力修改 (Bakdata.r3)
在**“武将三项能力修改”**标签页中：
* **全武将数据表格 (384人)**：显示序号、姓名、统御、武力、智力、三维总和；支持点击表头升降序排序与姓名实时过滤。
* **单人精确修改**：提供 **武力 (0~100)**、**智力 (0~100)**、**统御 (0~100)** 的数值微调框，附带“⚡ 三项全满 100”一键快捷满属性。
* **批量增强工具**：支持一键全员武力/智力/统御各 +10，或“⚡ 全员三维全部拉满 (100)”。

### 3. ⚙ 战斗与系统功能补丁 (Main.exe)
在**“战斗与系统功能补丁”**标签页中，复选框按需开启：
* **开启官方隐藏战斗 DEBUG 菜单**（强烈推荐）：
  解锁战场右键隐藏的 `DEBUG` 菜单（提供：**随意瞬移**、**控制所有人(含敌军)**、**控制友军**、**立即胜利**、**全军等级+5**、**AI挂机托管**等 7 大功能）。
* **全军无限制移动并可控制敌军**：硬编码解除移动范围与阵营限制。
* **策略值无消耗 (SP 不减)**：施放策略不耗蓝。
* **攻击性策略 100% 成功**：火计、落石、水计、混乱等策略必定命中。
* **兵力全满时仍可使用补给策略**：满血也能施放加血策略刷经验。
* **士气 100 时仍可使用激励策略**：满士气仍可继续激励练级。
* **士气为 0 仍不溃退逃跑**。
* **士气低于 30 仍不混乱**。
* **贼兵受到攻击必定反击**。
* **军乐队列队补蓝加速 (每5级+1)**。
* **战场天气锁定为晴天**。

### 4. ⚔ 战斗与事件剧本指令修改 (SNRD)
在**“战斗与事件剧本指令”**标签页中：
* **全章节剧本指令库 (Snr0d.r3 ~ Snr4d.r3)**：
  * 支持 0~4 全部 5 个章节，解析 15,000+ 条底层字节码事件与战斗控制指令。
* **触发条件与指令类型智能分类筛选**：
  * **触发条件过滤**：顺序执行、单挑、对话、进入城市/建筑、战场移到点/区域、战斗胜利、战斗失败、指定回合、撤退等。
  * **指令类型快捷过滤**：部署我军部队、部署敌军部队、武将单挑、改变人物AI、设置事件开关、检查条件、战斗胜利、战斗失败、部署非战斗人物、获得道具、援军出现等。
  * **实时全局搜索**：支持按人物名称、指令释义或触发条件模糊搜索。
* **展开式部队部署编辑器 (参考 Web 前端架构)**：
  * **我军部队部署 (`0x03`, 282字节)**：
    * **战斗宏观规则与主将**：自由设定是否允许撤退、战斗限制回合数（1~100）、是否继承上场回合数、敌方主将与我方主将选择。
    * **30 人我方部署席位**：全 30 席位树状表格展示，支持逐一设定登场武将（384武将点选或空置）、战场坐标 X/Y（0~99）、出场方式（直接出场 / 事件触发后出场）、关联事件 Flag、初始朝向（下/左/上/右）以及伏兵隐藏状态。
  * **敌军部队部署 (`0x22`, 392字节)**：
    * **30 支敌军部队席位**：全 30 席位树状表格展示，支持精细设定敌将、兵种（19兵种可选）、等级（Lv 1~99）、战场坐标 X/Y、出场方式、关联事件 Flag、朝向与伏兵状态。
    * **战场 AI 与附加目标**：支持 8 种 AI 模式（原地警戒、主动出击、原地待命、攻击仇人、移向坐标等），并动态切换附加目标（移动到特定坐标 X/Y 或追击特定仇人武将）。
    * **批量增强工具**：提供一键全员等级 +5 / -5 快捷微调。
  * **快速启动与确认流程**：
    * 在指令列表中单击或双击任意部署指令，均可一键弹出展开部署编辑器。
    * **弹窗快速确认**：弹窗底部常驻 **`✔ 确认`**（可按回车快速确认）与 **`✖ 取消`** 按钮，点击确认后静默应用修改并关闭弹窗（无打扰弹窗提示）。
    * **统一落盘保存**：确认后在主界面点击 **`💾 保存当前剧本指令`** 即可写回游戏剧本文件（`SnrXd.r3`）。
* **常用指令可视化微调卡片**：
  * **武将单挑指令 (0x10)**：自动识别发起方与迎战方武将，直接从 384 人下拉框中任意指定对阵双方。
  * **改变人物AI指令 (0x1C)**：直接选择目标武将与新 AI 模式。
  * **部署非战斗人物/场景行动 (0x01, 0x0A)**：直观配置人物、坐标 (X, Y) 与朝向。
  * **事件开关设置 (0x14)**：配置标志位与开启/关闭状态。
  * **获得道具 (0x1B)**：从 63 种宝物道具下拉框中选择。
  * **援军登场 (0x1A) / 部队撤退 (0x18)**：武将点选。
  * **阵营修改 (0x24, 0x28) / 战场放火放水 (0x27) / 剧情模式 (0x17)**。
* **底层十六进制字节码直接编辑**：
  * 支持对任意未知或特殊指令直接输入 Hex 字节码修改，具备字节长度一致性保护与参数格式校验，杜绝数据越界错位。
* **独立保存与自动备份**：
  * 提供“💾 保存当前剧本指令”，修改保存时自动生成 `SnrXd.r3.bak`。

### 5. 双重备份与一键还原
* 无论是程序补丁、武将三维、剧情台词还是剧本指令，首次保存时均会自动生成 `.bak` 备份文件。
* 底部常驻 **“🔄 还原原版备份 (.bak)”** 按钮，随时可将整个游戏目录还原至官方原版初始状态。
