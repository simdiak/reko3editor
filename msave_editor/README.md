# 《三国志英杰传》存档编辑器 (MSAVE Editor)

基于 Python 和 Tkinter 开发的独立《三国志英杰传》（DOS / Big5 版）存档查看与编辑器。
本模块不直接依赖现有的 Flask/Web 后端代码，具备完全独立的数据常量、二进制解析、修改回写与桌面图形界面。

## 目录结构

```
msave_editor/
├── constants.py     # 384位武将、势力军团、19种兵种、63件道具的独立映射与双向反查字典
├── parser.py        # MSAVE*.R3S 存档二进制结构解析与回写引擎（包含 Avatar 和 SaveFile）
├── ui.py            # 基于 Tkinter/ttk 的图形化用户界面（左右分栏布局、表单联动、8格道具编辑）
├── main.py          # 启动入口文件
└── samples/         # 提取自官方备份的 5 个真实章节存档样本（MSAVE0 ~ MSAVE4）
```

## 运行方式

在项目根目录下执行：

```bash
python3 msave_editor/main.py
```

或者直接指定要查看和编辑的存档路径：

```bash
python3 msave_editor/main.py ./msave_editor/samples/MSAVE0.R3S
```

## 核心特性与编辑功能

1. **左右分栏布局**：
   * **左侧列表区**：提供军团筛选、关键字实时搜索、只看有装备、表头点击排序功能。
   * **右侧编辑区**：
     * **初始状态留空**：未选择任何武将时居中显示占位提示；
     * **选中武将即刻展示编辑表单**：支持一键切换并实时联动。
2. **武将属性编辑**：
   * **所属军团**：下拉框选择（劉備、曹操、孫權、袁紹等所有势力）。
   * **当前兵种**：下拉框选择（19 种兵种：短兵、長兵、戰車、近衛隊、發石車、妖術師等）。
   * **等级 / 经验**：数字调节框（等级 1~99，经验 0~99）。
   * **当前兵力 / 士气**：输入框与调节框（兵力 0~65535，士气 0~100）。
   * **一键满级满兵力**：右上角提供“⚡满级满兵”快捷按钮（99级、6000兵、100士气）。
3. **完整 8 格道具装备编辑**：
   * 采用 2 列 x 4 行完整展示 **第 1 格至第 8 格**，不再受宽度挤压。
   * 每个格子都是独立的下拉选择框，支持选择 `(空)` 或全部 63 种武器、宝物、兵法书、药品。
   * 提供“清空8格”一键重置按钮。
   * 右侧修改后，左侧表格中的道具摘要与属性行会**实时同步刷新**。
4. **军团金钱修改**：
   * 顶部信息栏中金钱变为可编辑输入框（0 ~ 10000 黄金）。
   * 提供“满钱(10000)”快捷按钮。
5. **保存与另存为**：
   * 顶部常驻 **“💾 保存修改”** 与 **“💾 另存为...”** 按钮。
   * 点击后自动将内存中修改后的金钱、所有武将属性、兵力、8 格道具一次性完整写回二进制存档（严格保持 8789 字节），游戏中直接读取生效。
